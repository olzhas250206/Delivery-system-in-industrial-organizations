# Delivery-system-in-industrial-organizations
Supply Management System — өнеркәсіптік ұйымдардағы материалдар мен жинақтауыштардың жеткізілуін, қоймадағы қорларды және тапсырыстарды автоматтандырылған түрде басқаруға арналған веб-қосымша.

Жобаның негізгі мақсаты — материалдарды жеткізу процесін цифрландыру, жеткізушілер мен тапсырыстар туралы ақпаратты бір жүйеде сақтау, қоймадағы материалдардың қозғалысын бақылау және қор мөлшері төмендеген жағдайда автоматты түрде ескерту жасау.

Жүйенің негізгі мүмкіндіктері
Жеткізушілер туралы ақпаратты басқару;
Материалдар мен жинақтауыштарды есепке алу;
Қоймаларды басқару;
Жеткізу тапсырыстарын құру және бақылау;
Тапсырыс құрамындағы материалдардың санын сақтау;
Қоймадағы материалдардың кіріс және шығыс қозғалысын бақылау;
Материалдардың қалдығын автоматты түрде жаңарту;
Қор деңгейі төмен болған жағдайда автоматты ескерту жасау;
Жеткізу тапсырыстары мен қойма қозғалыстары бойынша ақпаратты талдау;
Деректерді қосу, өңдеу, жою және қарау операцияларын орындау;
Dashboard арқылы негізгі көрсеткіштерді бақылау.
Қолданылған технологиялар
Python — негізгі бағдарламалау тілі;
Flask — backend және REST API әзірлеу үшін;
MySQL — деректер қорын сақтау және басқару үшін;
HTML5 / CSS3 / JavaScript — веб-интерфейсті әзірлеу үшін;
SQL — деректер қорымен жұмыс істеу үшін;
SQL Triggers — қойма қалдықтарын автоматты жаңарту және төмен қор туралы ескерту жасау үшін;
REST API / JSON — frontend пен backend арасындағы деректер алмасу үшін.
Деректер қоры

Жүйеде supply_management атты MySQL деректер қоры қолданылады. Негізгі кестелер:

suppliers — жеткізушілер;
materials — материалдар;
warehouses — қоймалар;
orders — тапсырыстар;
order_items — тапсырыс құрамындағы материалдар;
stock_movements — қоймадағы материалдардың қозғалысы;
alerts — жүйелік ескертулер.

Деректер қоры арасындағы байланыстар сыртқы кілттер арқылы ұйымдастырылған. Сонымен қатар, SQL триггерлері арқылы кейбір операциялар автоматтандырылған.

Архитектура

Жоба клиент-сервер архитектурасы негізінде құрылған. Backend бөлігі Python және Flask көмегімен жасалған, ал frontend HTML, CSS және JavaScript технологияларына негізделген.

Frontend жүйесі REST API арқылы Flask серверімен байланысып, деректерді JSON форматында қабылдайды және жібереді.

Автоматтандыру

Жүйенің маңызды ерекшеліктерінің бірі — қойма операцияларын автоматтандыру. Жеткізу тапсырысы қабылданған кезде материалдардың қоймадағы саны автоматты түрде жаңартылады. Егер белгілі бір материалдың қалдығы белгіленген шектен төмен түссе, жүйе автоматты түрде ескерту қалыптастырады.

Бұл тәсіл қоймадағы қорларды бақылауды жеңілдетіп, материалдардың жетіспеушілігін алдын ала анықтауға мүмкіндік береді.

Жобаның мақсаты

Жоба өнеркәсіптік ұйымдардағы жеткізу процесін басқаруды жеңілдетуге және материалдар туралы ақпаратты бір орталықтандырылған жүйеде сақтауға бағытталған. Жүйе жеткізушілерден бастап қоймадағы материалдардың қозғалысына дейінгі негізгі процестерді бақылауға мүмкіндік береді.
